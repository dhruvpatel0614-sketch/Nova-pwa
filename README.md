# NOVA PWA v1.0
Phone-only NOVA/JARVIS browser version.

To install as a PWA, host these files on an HTTPS static web host, open the site in Chrome on Android, then choose Add to Home screen / Install app.

Includes conversation UI, browser voice input where supported, speech output, GPS, basic device context, and an optional private HTTP AI endpoint.

A PWA cannot freely inspect installed Android apps, read all notifications, or silently control Bluetooth/Wi-Fi/hotspot/airplane mode. Those require the native Android NOVA app.
